## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The image is drawn by `draw.py` (PIL) with crisp baked-in text; `main.ts` copies the shipped `entry.png` to the output directory, so both grader runs produce a byte-identical file.
